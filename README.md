# AI Powered Mental Health Support Chatbot

## Overview

Developed an AI-powered Mental Health Support Chatbot that provides emotional support, sentiment analysis, and personalized wellness recommendations using Artificial Intelligence, Natural Language Processing (NLP), and Machine Learning.

The chatbot analyzes user conversations, identifies emotional states, provides supportive responses, and helps improve mental wellbeing through intelligent interaction.

## Key Features

- Real-time Mental Health Assistance
- Sentiment Analysis and Emotion Detection
- Personalized Wellness Recommendations
- AI-Powered Conversational Support
- User-Friendly Chat Interface
- Secure and Privacy-Focused Communication

## Technologies Used

- Python
- Machine Learning
- Natural Language Processing (NLP)
- Sentiment Analysis
- Generative AI
- Google Gemini API

## Project Objectives

- Provide instant emotional support
- Analyze user sentiment and emotions
- Deliver personalized mental wellness guidance
- Improve accessibility to mental health resources
- Enhance user engagement through AI conversations
